## ⪩ Frame Notes v1.0.0 ⪨

First release: pause a video, press `1`, `2` or `3`, mark the element on the frame, type a line. The notes land in a
text file next to the video with After Effects style timecodes and a PNG of each marked frame.

---

### ⤷ Added ˎˊ˗

- **Three note types on three keys** — `1` FIX, `2` ADD, `3` REMOVE. The key pauses the video and starts a note at
  the current frame; `Enter` saves, `Esc` cancels.
- **Region on the frame** — while a note is being written, drag a rectangle on the video or click to put a point.
  The frame is saved as a PNG with the mark drawn on it, and the mark shows over the video whenever the note is
  selected.
- **Notes file next to the video** — `<name>_notes.txt`: a short header and one tab-separated line per note
  (timecode, type, text, optional region and image name). Images go to `<name>_notes\`. The file is rewritten
  after every change; opening the video again brings the notes back.
- **After Effects timecodes** — `h:mm:ss:ff` from the file's real frame rate; drop-frame with `;` for 29.97 and
  59.94, as in the AE timeline. The rate is read from the MP4 / MOV or WebM container and can be overridden in
  the header.
- **Mini timeline** — ruler, playhead, a coloured marker per note with the first words of its text; hover for the
  full note and its frame image, click to seek, wheel to zoom.
- **Notes panel** — every note with its thumbnail; `↑` / `↓` walk the notes and move the video with them, `F2`
  edits, `Delete` removes.
- **Frame stepping** — `←` / `→` one frame, `Shift` + arrows ten, `Home` / `End`.
- **Copy** — `Ctrl+C` outside a text field puts the whole notes file on the clipboard.
- **Open by drop, dialog, argument or recent list** — drop a file on the window, `Ctrl+O`, "Open with" in Explorer,
  or pick from the recent files on the start screen.
- **Portable** — one `FrameNotes.exe`, data in `frame-notes_data\` next to it.
- **Self-update** — new releases are detected on launch, downloaded in the background (switch: *Download updates
  automatically*, on by default), verified by size and SHA-256 and installed by **Restart to update**.
