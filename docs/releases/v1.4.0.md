## ⪩ Frame Notes v1.4.0 ⪨

A new version is now announced in a window with its release notes, so an update is hard to miss, and the app window has one fixed size.

---

### ⤷ Added ˎˊ˗

- **Update window** — when a newer version is found, a window opens over the app with the new version number, the installed version, the download size and the release date, and the release notes. **Install** downloads the update, shows the progress and restarts into the new version as soon as the file is verified; with automatic download on it shows `Downloading… 42%` and then **Restart to update**. **Later** (or `Esc`, or a click outside the window) closes it; it does not open again by itself for the same version until the next launch, and the version label at the right of the header opens it again at any time. A failed download shows the reason and **Try again**. The window never opens for a check that finds nothing or fails.

### ⤷ Changed ˎˊ˗

- **Fixed window size** — the window is 1280 x 800 and can no longer be resized or maximized (the maximize button is gone and a double click on the title bar does nothing). On a smaller screen it opens at 1152 x 720, 1024 x 640 or 960 x 600, the largest that fits. The window position is still remembered.

### ⤷ Removed ˎˊ˗

- **Saved window size and maximized state** — `settings.json` keeps only the window position; the old size and maximized entries are ignored and dropped on the next save.
