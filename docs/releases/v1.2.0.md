## ⪩ Frame Notes v1.2.0 ⪨

The app now looks for a new version every 5 minutes while it runs, the check interval setting is gone, and a version downloaded in the background still installs only on **Restart to update**.

---

### ⤷ Changed ˎˊ˗

- **Update check every 5 minutes** — besides the check at launch the app checks GitHub Releases every 5 minutes
  while it is open, so a new version shows up in the version chip soon after it is published. A failed check is
  retried later with a growing wait (10, 20, 40 minutes, then once an hour), and no check is made while Windows
  reports no network connection. With *Download updates automatically* on (the default) the new version is
  downloaded in the background; installing it still needs **Restart to update**.

### ⤷ Removed ˎˊ˗

- **Check interval select** — the *Check for updates* select (every 30 minutes, hour, 6 hours, day, week) is gone
  from the version popover. The value stored by 1.1.0 is ignored and removed from the settings file the next time
  it is saved.
