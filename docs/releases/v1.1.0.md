## ⪩ Frame Notes v1.1.0 ⪨

Each review now lives in one folder next to the video, with a readable version of the notes for people, and the
recent list gets a right-click menu.

> Notes written by 1.0 are moved into the new folder the first time 1.1 opens their video. Nothing in the notes
> changes, but 1.0 no longer finds them afterwards, so update every copy of the app you use for the same videos.

---

### ⤷ Added ˎˊ˗

- **Readable notes** — next to the notes file the app now writes `<name>_notes.md`: the video name, a line with
  the frame rate, duration and the count per type, then one line per note (`0:00:12:07 · FIX · text`) with its
  frame image right under it. Plain Markdown, so it reads well in Notepad, a chat or any Markdown viewer, and it
  is rewritten after every change.
- **Copy the readable text** — the **Copy** button in the header has an arrow menu: **Notes file** (`Ctrl+C`, as
  before) or **Readable text** (`Ctrl+Shift+C`), which leaves the image lines out so it pastes cleanly into a chat.
- **Recent menu** — a **Recent** button in the header lists recent videos while a video is open; the list on the
  start screen and this menu show how many notes and frame images each video has.
- **Right-click menu on recent videos** — **Open**, **Reveal folder** (the notes folder in Explorer, or the video
  when it has none), **Delete notes** (the item turns into "Delete 3 notes and 2 frames?" and needs a second click;
  it removes the whole notes folder and refuses when the folder holds files the app did not write) and **Remove from
  recent** (only the list entry). Works for the open video too: deleting its notes starts its review again empty.
- **Update check interval** — besides the check at launch the app now checks for a new version every 30 minutes;
  choose every hour, 6 hours, day or week under *Check for updates* in the version popover.

### ⤷ Changed ˎˊ˗

- **One folder per review** — `promo_v3.mp4` now gets `promo_v3_notes\` holding `promo_v3_notes.txt` (the notes,
  same format as before), `promo_v3_notes.md` (the readable version) and `frames\` with the images, instead of a
  text file beside the video plus a separate images folder. Notes from 1.0 are moved into this layout once, when
  their video is opened: the images first, then the text file, so an interruption leaves nothing broken and the
  next open finishes the move. **Reveal** opens the folder with the notes file selected; its third entry is now
  **Frames**.
